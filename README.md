## 🌟 Tentang Proyek

**Web Makanan** merupakan salah satu proyek pengembangan web yang saya buat untuk melatih kemampuan dalam membangun tampilan website menggunakan teknologi dasar web.

Website ini dirancang untuk menampilkan informasi makanan, menu favorit, serta visual kuliner yang menarik dengan antarmuka yang bersih dan nyaman digunakan oleh pengguna.

Proyek ini menjadi bagian dari perjalanan saya dalam mempelajari dunia **Web Development** dan membangun portofolio sebagai calon software developer.

> *"Makanan yang lezat layak mendapatkan tampilan website yang menarik."*

---

## 🎯 Tujuan Proyek

* Melatih kemampuan HTML dan CSS
* Membuat website kuliner yang menarik
* Mempelajari struktur halaman web yang baik
* Meningkatkan kemampuan desain antarmuka (UI)
* Menjadi salah satu proyek portofolio pengembangan web

---

## ✨ Fitur Utama

### 🍛 Daftar Menu Makanan

Menampilkan berbagai menu makanan dengan tampilan yang menarik.

### 📖 Informasi Detail Makanan

Pengguna dapat melihat informasi tambahan mengenai makanan yang tersedia.

### 🎨 Desain Modern dan Minimalis

Fokus pada kenyamanan pengguna dan kemudahan membaca informasi.

### 📱 Responsive Design

Tampilan website dapat menyesuaikan berbagai ukuran layar.

### ⚡ Navigasi Sederhana

Struktur halaman yang mudah dipahami dan digunakan.
